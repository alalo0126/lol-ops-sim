# 이른 갱(1:30~5:00) 검수: 정리 (2026-11-16)

`python -m sim.early_gank_check --games 400` → `reports/early_gank.md`(전체 표).
실제는 리플레이 1초 동선(26.21 한국 챌린저, 1:30~5:00 동선이 있는 정글러 93명), 시뮬은 규칙 봇 양 팀 400판과 학습 정글러 stage18_b·stage18_c 각 400판(상대 규칙 봇).

## 질문

stage18_c는 첫 갱을 1.6분에 가고(실제 2.5분) 규칙 봇 대비 승률 차가 가장 컸다(+0.248). 그래서 시뮬이 아주 이른 갱을 과대평가한다고 봤다.

## 결과: 갱 성공률은 과대평가가 아니다

| 1:30~5:00 라인 방문(8초 이상) | 실제 | 규칙 봇 | stage18_b | stage18_c |
|---|---|---|---|---|
| 방문당 정글러 관여 킬 | 56% ±9 | 34% ±3 | 59% ±4 | 57% ±3 |
| 방문당 정글러 사망 | 6% ±4 | 3% ±1 | 7% ±2 | 3% ±1 |
| 방문 시작 분 적 라이너 체력 | 0.72 | 0.89 | 0.88 | 0.92 |

- 학습 정글러의 이른 방문 킬 비율은 실제와 같고, 규칙 봇은 오히려 실제보다 낮다.
- 이른 킬 하나의 값도 실제와 비슷하다. 1:30~4:00 첫 킬 뒤 10분까지 킬한 팀의 골드 차 변화: 실제 +577 ±439(69판), 규칙 봇 +302 ±268(198판). 정글러가 관여한 킬은 실제 +628, 시뮬 +625.

## 진짜 원인: 규칙 봇 버그 + 1레벨 카정

- stage18_c는 거의 매 판(96%, 실제 11% ±6) 1레벨에 **적 블루·두꺼비를 먼저 먹고** 라인으로 간다.
- 상대 규칙 봇은 뺏긴 캠프 앞에서 **리젠될 때까지(약 2분) 멈춰 있었다.**
  - 첫 동선의 다음 캠프를 고르는 조건(`choose`: 리젠 시각이 미래이면 감)과, 이동 중 다시 확인하는 조건(`still_valid`: 리젠까지 이동 시간 + 20초 안이어야 함)이 달랐다.
  - 그래서 고르기 → 5초 뒤 취소 → 다시 고르기를 되풀이했다. 갈 때마다 엣지를 처음부터 다시 걸어, 캠프에 도착하지도 못했다.
  - 예: 시드 3, 상대 정글러가 1:44~3:40 늑대 옆에 서 있었다.
- 그 결과 stage18_c 판의 상대 정글러는 5분에 캠프 5.5개를 먹었다(stage18_b 판 8.0개). 골드는 C 정글러가 5분에 +321 앞섰다.

## 수정

`sim/bots.py` JunglerBot.choose: 첫 동선 캠프는 첫 생성 전이거나 리젠이 `이동 시간 + 20초` 안일 때만 가고, 아니면 건너뛴다(`still_valid`와 같은 조건).

| | 수정 전 | 수정 후 |
|---|---|---|
| C 판 상대 정글러 5분 캠프 | 5.5 | 7.1 |
| C 정글러 5분 골드 차 | +321 | +53 |
| 규칙 봇 대비 20분 승률 차(800판) A | +0.199 | +0.187 (+0.161~+0.213) |
| B | +0.209 | +0.190 (+0.164~+0.216) |
| C | +0.248 | **+0.164** (+0.137~+0.192) |

- 수정 뒤에는 C가 가장 낮다. C가 이긴 몫의 대부분이 이 버그였다. 주 모델은 그대로 B를 추천한다.
- 4단계 정글 기준(`sim.run_baseline --games 300`)은 불일치 1·주의 3, 라이너 기준(`sim.laner_eval --games 150`)은 OK 87·주의 18·불일치 3으로 둘 다 그대로다. 값은 거의 같다.
- 학습 정글러는 수정 전 시뮬로 학습했다. 재학습은 하지 않았다(B는 버그와 무관하게 앞서고 승률 차 구간도 겹친다).

## 남은 차이 (다음 후보)

1. **초반 라이너 체력**: 실제 방문 시작 분 적 라이너 체력 0.72, 시뮬 0.89~0.92. 실제 이른 방문 킬이 규칙 봇보다 높은 것(56% vs 34%)과 같은 방향이다(1분 프레임 기준이라 정확하지 않음).
2. **이동 취소 때 위치 되돌림**: 이동 중 작업이 취소되면 지금까지 걸은 거리를 버린다. 규칙 봇 40판에서 정글러당 20분에 2.9번, 한 번에 평균 1,900 거리(약 5초)를 잃는다. 작지만 버그라서 고칠 후보로 남긴다.
3. 1레벨 카정 자체의 비용(실제 11%): 시뮬에서 적 라이너·정글러가 버프 근처에서 맞서는 일이 드물 수 있다. 수정 뒤에도 C는 규칙 봇보다 +0.164 앞선다.
