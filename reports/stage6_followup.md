1차에서 학습 정글러는 크게 뒤처진 미드를 경기당 26번 갱했다(발각 1%, 성공 95%). 처치 골드가 늘 300이라 같은 라이너를 계속 잡아도 손해가 없었기 때문이다. 현상금 규칙을 넣자 우위가 줄고 갱이 여러 라인으로 퍼졌지만, 여전히 실제 범위 밖이다.

남은 원인: 갱 성공 확률식(bias 1.6)은 규칙 봇의 10분 KDA에만 맞춰져 있다. 규칙 봇은 레벨·아이템이 비슷한 상태에서 경기당 10번 갱하고 45% 성공하는데, 학습 정글러는 앞선 상태(레벨 +1.9, 아이템 +1,330)에서 2:1~3:1로 들어가 77% 성공한다. 실제 데이터에는 갱 시도 기록이 없어 이 영역의 성공률을 직접 맞출 수 없다.

## 갱 성공식만 낮춰 보기(되돌림)

| 시도 | 규칙 봇(상대) | 학습 정글러(2차 정책, 재학습 전) |
|---|---|---|
| bias 1.6 → 0.1, 규칙 봇 갱 간격 60 → 20초 | 10분 KDA는 맞지만 갱만 하다 10분 정글 CS 48(실제 70), 경험치 불일치 | 20분 킬 7.2 |
| 레벨·아이템 차 계수를 실제 킬 회귀값(0.245 / 0.396)으로 | 변화 없음 | 20분 킬 11.1(거의 그대로) |
| 발각 불이익 −1.6 → −2.5, 갱 뒤 경계 300초 | 10분 킬 1.6, 15분 경험치 불일치 | 20분 킬 8.4 |

갱 성공식 하나로는 '규칙 봇이 실제처럼 갱해서 10분 KDA·CS가 맞는 것'과 '학습 정글러가 실제보다 많이 잡지 않는 것'을 동시에 맞출 수 없다. 학습 정글러는 상대 점멸이 없고, 안 보이고, 2:1인 순간만 골라 들어가는데, 시뮬에서는 그런 순간이 실제보다 훨씬 자주 온다. 실제로 그런 순간을 드물게 만드는 웨이브 위치·라이너 위치·시야가 시뮬레이터에 없기 때문이다. 실제 분 프레임에 라이너 좌표가 있어서 라이너가 포탑에서 얼마나 나와 있는지 분포는 맞출 수 있다.

## 라인 모듈용 실제 분포(미리 뽑아 둠)

1단계 1,000판 3~14분 분 프레임, 살아 있는 라이너. 위치 = 우리 1차 포탑까지 거리 ÷ (우리 + 적 1차 포탑까지 거리), 0 = 우리 포탑, 1 = 적 포탑. '라인 위' = 두 포탑 사이 경로에서 3,000 안.

| 역할 | 라인 위 비율 | 위치 10% / 25% / 중앙 / 75% / 90% | 우리 포탑 근처(0.2 미만) |
|---|---|---|---|
| 탑 | 78% | 0.14 / 0.25 / 0.44 / 0.61 / 0.73 | 19% |
| 미드 | 74% | 0.15 / 0.25 / 0.41 / 0.54 / 0.67 | 17% |
| 원딜 | 73% | 0.13 / 0.23 / 0.41 / 0.57 / 0.71 | 21% |
| 서폿 | 55% | 0.16 / 0.27 / 0.45 / 0.60 / 0.71 | 15% |

지금 시뮬 라이너는 라인 가운데 노드(0.5)나 포탑 노드 두 곳에만 있다. 라인 모듈은 이 분포를 재현하고, 갱 성공을 '라이너가 포탑에서 얼마나 나와 있나'에 묶는 방향이다.

## 갱 맞교환 사망(라인 모듈 대신)

라인 모듈을 만들기 전에 실제 라이너 위치가 갱 결과를 얼마나 바꾸는지부터 봤다. 정글러 관여로 죽은 라이너의 위치 분포는 전체 라이너 위치 분포와 거의 같았다(기울기 +0.1, 위 표 기준). 실제 데이터로는 라이너 위치가 갱 킬 확률을 설명하지 않아서, 위치 모듈로 갱 과다를 고칠 근거가 없었다.

대신 실제와 시뮬에서 똑같이 잴 수 있는 기준을 썼다. 분 프레임에서 정글러가 적 라이너 2,000 안에 있던 순간을 뽑아 30초 안의 결과를 본다.

| | 그런 순간(경기당, 3~14분) | 그 라이너가 정글러 관여로 죽음 | 정글러가 죽음 |
|---|---|---|---|
| 실제 1,000판 | 3.6 | 26% | 24% |
| 학습 정글러 2차(맞교환 전) | 3.7 | 31% | 6% |
| 학습 정글러 3차(맞교환 0.25 넣고 재학습) | 2.8 | 23% | 14% |

시뮬 갱은 실제보다 훨씬 안전했다. 갱이 성공해도 정글러가 맞교환으로 죽을 확률(success_attacker_death 0.25)을 넣고, 실패 시 사망 0.15, 조우 교전 0.03으로 규칙 봇 10분 KDA와 4단계 기준을 다시 맞췄다(불일치 없음).

### 6단계 비교 다시(3차 정책, reports/stage6_compare.md, 이전 결과는 data/stage6_v1/)

- 범주 분포(실제 / 학습): 우리 정글 23% / 9%, 카정 11% / 1%, 라인 개입 25% / 55%, 오브젝트 16% / 25%, 강가 7% / 5%, 귀환 18% / 5%. 라인 개입 쏠림은 그대로다.
- 그 범주로 붙은 1분의 결과는 실제와 맞는다: 라인 개입 1분 킬 관여 74% / 74%(이전 70%), 사망 27% / 35%. 오브젝트 1분 에픽 처치 88% / 79%.
- 첫 1분을 실제 선택으로 묶으면 20분 예측 승률 −1.0%p(95% CI −1.4~−0.5). 이전 −0.4%p보다 학습 정글러 쪽이 조금 더 낫다고 본다.
- 실제 대조(관찰 값, 킬이 범주에 섞여 과대)도 대부분 칸에서 라인 개입 쪽이 우리 정글·귀환보다 +2~+4%p 높다. 실제 경기에서도 라인 개입한 1분이 결과가 좋았다는 뜻이라, 학습 정글러의 갱 선호를 시뮬레이터 오류로만 보기 어렵다.
- 여전히 남은 시뮬레이터 차이: 실제 상태를 옮긴 1분의 정글 CS가 3~4로 실제 7~8의 절반(캠프 타이머를 알 수 없어서, 조건 차이), 카정 1%(시뮬 카정 반사실 −2.1%p).
