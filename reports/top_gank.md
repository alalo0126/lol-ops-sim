# 탑 갱이 거의 없던 원인

## 1. 시뮬의 라인별 갱 결과가 실제와 반대였다

`python -m sim.lane_visits`(라인별 표 추가): 3~18분 라인 방문(라인 구역 연속 5초 이상)마다 방문~끝+10초 안 정글러 관여 킬.

| | 탑 | 미드 | 바텀 |
|---|---|---|---|
| 실제 리플레이(64명, 방문 700번) 방문당 킬 | 48% | 26% | 42% |
| 시뮬 규칙 봇(보정 전) | 32% | 33% | 41% |
| 시뮬 규칙 봇(보정 후) | 48% | 32% | 42% |

실제로는 탑 갱이 가장 잘 나고 미드가 가장 안 난다(탑은 길고 외딴 라인, 미드는 짧고 양옆 지원). 시뮬 갱 성공식에는 라인 차이가 없었다.
→ `gank.coef.lane_bias` 추가(로그오즈, 대상 라이너의 라인): 탑 +0.96, 미드 −0.54, 바텀 +0.34. 규칙 봇 200판 고정점 반복으로 맞춤. 정글 4단계 400판 불일치 없음(10분 KDA 그대로).

## 2. 학습 정글러가 탑 갱을 아예 시도하지 않게 굳어 있었다

보정 뒤 stage8_a에서 200회 더 학습(models/stage9_a)해도 탑 갱 0%. 정책의 탑 갱 확률이 고를 수 있는 결정에서 평균 0.002%(중앙 0.00002%)로 굳어, 탑 갱 결과를 다시 볼 기회가 없었다(초기 학습 때 시뮬 탑 갱 가치가 낮아 사라진 뒤 회복 못 함).
→ stage9_a의 탑 갱 출력 편향에 +8을 더해 확률을 규칙 봇 수준(평균 7%)으로 되살리고 200회 학습(models/stage9_b). 학습 뒤에도 평균 3%로 유지 = 시뮬이 이제 탑 갱을 가치 있게 본다.

## 결과 (1초 동선 3~18분 행동 비율 200판, 승률 400판)

| | stage9_a | stage9_b | 실제 |
|---|---|---|---|
| 규칙 봇 대비 20분 승률 차 | +0.096 (+0.059~+0.133) | +0.131 (+0.094~+0.169) | - |
| 탑 갱 | 0.0% | 2.9% | 7.4% |
| 미드 갱 | 12.5% | 6.6% | 10.4% |
| 바텀 갱 | 9.0% | 11.3% | 7.1% |
| 아랫게 | 12.5% | 10.5% | 6.5% |
| 오브젝트 합 | 13% | 14% | 7% |

탐색을 되살린 쪽이 승률도 더 높다 → 이전 정책은 탑을 버린 국소 최적이었다. 남은 차이: 바텀 쏠림(바텀 갱·아랫게·용), 카정 0%(실제 6%)도 같은 '확률이 굳은 행동' 문제일 수 있음.

    python -m sim.lane_visits --policy models/stage8_a/policy_latest.npz --games 200
    python -m sim.train --init models/stage8_a/policy_latest.npz --iters 200 --seed0 700000 --out models/stage9_a
    # stage9_a pi 마지막 층 편향[A_GANK] += 8 → models/stage9_top/init.npz
    python -m sim.train --init models/stage9_top/init.npz --iters 200 --seed0 800000 --out models/stage9_b
