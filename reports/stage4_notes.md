# 4단계 기준선 메모

## 판정 (2026-10-19, 1단계 1,000판 기준)

**미통과.** 2~6분 지표는 실제 분포 안에 들지만, 10분 정글 CS·골드·경험치가 실제 p10보다 낮다(10분 CS 56 vs 실제 72, 골드 3,436 vs 4,246, 경험치 3,249 vs 4,132). 설계 문서 기준대로 5단계로 넘어가지 않는다.

## 1,000판에서 달라진 점

- 첫 풀캠이 340판 때보다 느리다. 3분 정글 CS 중앙값 24 → 20, 3분 프레임에 24를 넘긴 비율 50% → 44.5%. 그래서 `dps_level1`을 125 → 118로 다시 맞췄다.
- 정글러 10분 킬·데스·어시스트 평균 2.2 / 1.1 / 1.6.

## 차이가 나는 이유

1. **파밍 효율.** 시뮬 정글러는 3~10분 420초 중 약 170초를 캠프까지 걷는 데 쓴다(캠프당 약 17초). 실제 정글러는 같은 시간에 캠프 약 12개를 먹고도 처치 관여가 3.8회다. 엣지 계수(1.0~1.3), 처치 시간 모델, 리스폰 맞춰 도는 동선 중 무엇이 틀렸는지는 실측 없이는 가를 수 없다.
2. **처치 관여.** 실제 정글러가 관여한 10분 전 킬은 라인 52%, 정글 31%, 강가 18%(516판). 정글·강가 조우 교전(`sim/game.py _skirmish`)을 넣었지만, 교전을 늘리면 킬보다 데스와 잃는 파밍 시간이 먼저 늘어 10분 골드가 오르지 않는다.
3. **카정.** 실제 적 정글 CS 비중은 중앙 10%(471판), 규칙 봇은 2%.

## kk 피드백 반영 (2026-10-20)

- 우물 이속 효과(wiki:Homeguard, V26.01: +80%가 4초에 걸쳐 +40%, 정글에 들어가면 사라짐, 14분 전 부활 시 +75%)를 넣었다. 우물에서 정글 입구까지 거리 3500은 미검증 추정값이다.
- 정글러 챔피언을 1,000판 실제 픽 비율(리 신 20%, 키아나 10%, 제이스 7% 등 47명)로 뽑고, 기본 이속은 Data Dragon 값을 쓴다. 가중 평균은 340.5로 기존 고정값 345와 비슷하다.
- 결과: 10분 골드 3,436 → 3,485, 정글 CS 56 그대로. 귀환 횟수가 적어 우물 이속 효과의 몫이 작고, 차이의 주원인은 아니었다.

## 실측하면 미검증 값을 검증 값으로 바꿀 수 있는 것 (연습 모드)

- 캠프 사이 이동 시간: 블루→칼날부리, 칼날부리→레드, 레드→돌거북, 돌거북→늑대(반대편), 우물→블루 / 레드
- 레벨 1 캠프별 처치 시간(대표 정글 챔피언 1~2명)
- 강타 두 번째 충전 시각, 보너스 간식이 처음 들어오는 시각

## kk 연습 모드 실측 반영 (2026-10-20)

- 이동 시간: 시뮬 그래프가 이미 실측과 1초 안팎으로 맞았다(칼날부리→레드 5.3 vs 6, 늑대→칼날부리 11.4 vs 11.5, 돌거북→아래 바위게 13.2 vs 13). 레드→돌거북(4.9 → 7), 블루→늑대 구간, 우물 출발 3개 구간만 실측에 맞춰 고쳤다. 우물 출발은 이제 17 / 16 / 15초로 실측과 같다.
- 우물 이속 효과: 실측 우물 안 763(+115%), 라인 복귀 구간 585(+65%). 위키의 +80%→+40%보다 크다.
- 처치 시간: 보정값(dps_level1) 대신 마스터 이 실측 6개 캠프 시간을 기준으로 쓴다. 이제 첫 풀캠·2·3분 지표도 검증 대상이다.
- 강타 2번째 충전 2:20, 보너스 간식 첫 시각 2:30(먼저 추정한 값과 같음).
- 결과: 시뮬 첫 풀캠 중앙 3:24. 실제 2분 정글 CS 중앙 12(시뮬 8). 실측 마스터 이 처치 시간이 1,000판 챌린저 정글러보다 느리거나, 동선이 다르다.

## 1,000판에서 본 실제 첫 풀캠 동선 (1·2·3분 위치와 정글 CS)

가장 흔한 세 가지:
- 블루 시작 → 2분 칼날부리(12) → 3분 아래 바위게(24): 78판
- 칼날부리 시작 → 2분 우물 근처(12) → 3분 위 바위게(24): 70판 이상
- 레드 시작 → 2분 늑대(12) → 3분 위 바위게(24): 35판 이상

즉 흔한 동선은 3분 전에 6캠프를 끝내고 바위게에 가 있다. 칼날부리 시작은 3캠프 뒤 2분에 우물 근처에 있다(귀환인지 본진 가로지르기인지 1분 프레임으로는 모름).

## kk 풀캠 실측과 동선 반영 (2026-10-20)

- kk가 이어서 잰 풀캠(마스터 이, 강타 1번, 당겨먹기): 칼날부리 → 돌거북 → 레드 → 늑대 → 두꺼비 → 블루, 블루 처치 3:00, 위 바위게 도착 3:03.
- 캠프별 처치 시간과 구간 이동 시간을 따로 더하면 같은 동선이 3:29에 끝난다. 처치 시간 안에 다음 캠프 쪽으로 걷는 시간(당겨먹기)이 들어 있어서다. 차이를 이동 5구간에 나눠 `pull_overlap_s` 6초로 넣었다. 시뮬은 이제 같은 조건에서 블루 3:00, 바위게 3:01.
- 동선(sim/params.json routes):
  - 칼날부리 시작 풀캠(129): kk 실측 동선 + 위 바위게
  - 칼날부리 시작 3캠프 후 귀환(70): 칼날부리 → 레드 → 돌거북 → 귀환 → 늑대 → 두꺼비 → 블루 → 위 바위게. 시뮬은 1:57 우물(12 CS), 2:57 바위게(24 CS)로 1,000판의 "2분 우물 근처 12 → 3분 위 바위게 24"와 같다.
  - 레드 시작: 레드 → 돌거북 → 칼날부리 → 늑대 → 두꺼비 → 블루 → 위 바위게. 시뮬 2:00 늑대(12 CS)로 실제와 같다.
  - 블루 시작: 블루 → 두꺼비 → 늑대 → 칼날부리 → 레드 → 돌거북 → 아래 바위게.
- 귀환 채널은 위키 8초를 그대로 쓴다(kk는 7초로 기억).
- 결과(400판): 2~8분 지표 모두 OK, 10분 정글 CS 64·골드 3,693·경험치 3,663은 주의(실제 72 / 4,246 / 4,132), 레벨 OK. 불일치는 15분 골드·경험치뿐이다. 첫 풀캠 중앙 3:11.
- 남은 차이: 4분부터 골드가 조금씩 벌어져 15분에 커진다. 실제 정글러의 갱·교전 수입과 3분 이후 캠프 효율(동선 재활용)이 원인 후보다.

## 10분 지표 보강 (2026-10-20)

- **비교 기준을 양 팀 정글러 둘 다로 바꿈.** 시드 선수만 보면 승률 57.7%(995판)라 10분 골드가 상대 정글러보다 약 160 높다(4,246 vs 4,085). 시뮬은 두 정글러가 같은 봇이므로 둘 다(2,000명)의 분포와 비교한다: 10분 골드 4,168, 정글 CS 70, 경험치 4,074, 킬·데스·어시스트 평균 2.0 / 1.2 / 1.6. `tools/stage4_targets.py`가 `both_*` 키로 함께 저장한다.
- **시간 사용(3:20~10:00, 60판):** 캠프 처치 123초, 캠프로 걷기 115초, 갱 61초, 오브젝트 57초, 사망 19초, 귀환 16초. 실제 정글러 상점 방문(아이템 구매 묶음)은 1~10분에 평균 3.2회(첫 방문 중앙 3:30)라 귀환 횟수는 크게 다르지 않다.
- **처치 관여가 부족했음:** 시뮬 10분 킬·데스·어시스트 평균 1.5 / 1.35 / 0.9 vs 실제 2.0 / 1.2 / 1.6. 갱 성공 계수, 갱 간격 90→60초, 정글러가 킬을 가져갈 확률 0.55→0.5, 교전 합류(12초·0.7 → 18초·0.9)를 이 평균에 맞췄다(1.98 / 1.11 / 1.47). 그래서 KDA 행은 '보정'으로 표시하고 검증 근거에서 뺐다.
- **결과(400판):** 불일치 없음. 10분 골드 3,865·정글 CS 64·레벨 7은 실제 p25~p75 안(OK), 경험치 3,732는 주의. 15분 지표도 모두 p10~p90 안.
- **남은 차이:** 10분 정글 CS가 중앙값보다 6 낮다(캠프 약 1.5개). 레벨이 오르고 아이템을 사도 처치 시간이 거의 줄지 않는다(마스터 이 기준 칼날부리 2레벨 15초 → 6레벨·1,300골드 12초). 레벨·아이템에 따른 처치 시간 감소(dps_per_level, dps_per_1000_item_gold)는 아직 미검증 추정값이다.
