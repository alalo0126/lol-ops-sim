# 1:1 교전 층 초안 (sim/duel.py) — 1차 시험 결과

2026-11-28. 미드 1,000판(16.20) 상위 10명: Locke, Syndra, Sylas, Galio, Akali, Yone, Viktor, TwistedFate, Ekko, Yasuo.

## 만든 것
- `sim/duel.py`: 0.1초, 1차원 거리. 스킬 표(rules/champ_skills_16.23.json)의 쿨·소모·선딜·사거리·투사체 속도·폭·계수 사용.
  대상 지정/스킬샷/범위/자기 주변 판정, 스킬샷 회피(반응 0.4초 + 옆으로 빠지는 시간), CC 태그, 돌진 태그(거리 좁히기),
  미니언에 막히는 스킬(35%), 물러날 공간 500, 턴 교환 규칙(내 콤보가 더 세거나 상대 주력이 쿨이면 들어감).
- `sim/duel_check.py`: 챔피언별(실제 상대 빈도 가중) 시뮬 우위 vs 실제 10분 골드 차·솔로킬 차 순위 상관.

시뮬은 원거리 견제형(신드라·빅토르·TF)을 높게, 실제로 라인에서 이기는 근접 올인형(야스오 +554골드·솔로킬 +0.58, 로크 +275)을 낮게 본다.
챔피언당 실제 표본 24~60판이라 실제 골드 차의 오차가 ±150~200골드쯤이지만, 방향이 반대인 건 표본 탓만은 아님.

## 원인 후보(다음에 고칠 순서)
1. 패시브·특수 기술 없음: 야스오 바람 장막(W, 투사체 막기)·패시브 보호막, 요네·실라스·로크 패시브, 아칼리 장막. 게임 파일 태그만으론 효과를 못 씀 → 챔피언별 효과 표가 필요(사람 손 큼).
2. 웨이브 없음: 실제 라인은 CS 먹기 중 짧은 교환이고, 미니언 어그로·미니언 타고 넘기(야스오 E)·막타 때 노출이 근접형 이득의 원천. 지금은 60초 순수 1:1.
3. 룬·소환사 주문 없음(정복자·감전·점화·점멸).
4. 회복 없음(도란 반지, 두 번째 바람, 흡혈).
5. 지표 불일치: 시뮬은 '60초 체력 차', 실제는 '10분 골드 차'. 웨이브를 넣은 뒤 CS 차로 바꿔야 비교가 맞음.

## 미검증 값(HUMAN·PROFILE·KIT_OVERRIDES)
반응 0.4초, 회피 55%, 범위 지연 0.5초, CC 1초, 미니언 막힘 35%, 물러날 공간 500, 골드→능력치 비율, 챔피언별 피해 계산식 선택(Claude가 고름).

## 2차: 라인 10분 모델 (sim/lane_duel.py)

귀환(체력 30% 또는 1,250골드), 사망(검증 부활 시간 + 걸어오기 22초), 포션 2개, 점멸 도망, 상대 포탑 사거리 안으로 안 쫓기,

## 검증 데이터의 한계(중요)

뚜렷한 건 야스오(+13)·신드라(+8) 정도. 10명 순위 상관은 0.6 넘어야 우연이 아니라고 말할 수 있음.
