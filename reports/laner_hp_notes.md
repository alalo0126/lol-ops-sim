# 초반 라이너 체력 검수 (2026-11-16)

이른 갱 검수(`reports/early_gank_notes.md`)에서, 정글러가 라인에 갈 때 적 라이너 체력이 실제 0.72인데 시뮬은 0.9였다.
그래서 정글러가 방문할 때만이 아니라 전체 라이너 체력을 비교했다.

## 실제 vs 시뮬 (2~10분 분 프레임, 살아 있는 라이너)

실제는 1단계 1,000판(16.20, kk PC `data/raw`)이고, 리플레이 72판(26.21)도 거의 같다.
시뮬은 규칙 봇 120~200판이다. 계산은 `python tools/laner_hp_check.py 200`으로 한다(리플레이 실제 + 시뮬).

| 평균 / 50% 미만 | 실제 1,000판 | 시뮬 전 | 시뮬 후 |
|---|---|---|---|
| 탑 | 0.75 / 20% | 0.90 / 3% | 0.77 / 19% |
| 미드 | 0.76 / 17% | 0.90 / 4% | 0.78 / 16% |
| 원딜 | 0.81 / 13% | 0.84 / 9% | 0.80 / 14% |
| 서폿 | 0.82 / 12% | 0.88 / 6% | 0.83 / 12% |
| 15% 미만(탑·미드·원딜·서폿) | 2.1·1.8·2.6·1.5% | – | 2.3·2.1·1.2·1.4% |

- 실제는 2분부터 탑·미드 평균이 0.65로 떨어진다(1~2레벨 딜교환). 시뮬은 거의 꽉 차 있었다.
- 원인: 라인 회복(초당 0.0045, 분당 0.27)이 딜교환 피해(라이너 1분에 0.6~1번, 한 번 평균 0.055)보다 훨씬 컸다.
  예전에는 맞췄지만(6단계 후속) 그 뒤 로밍·귀환이 늘면서 딜교환 기회가 줄어든 것으로 보인다.

## 수정

- `laner.trade_damage`를 포지션별로 바꿨다: 탑 [0.06, 0.4], 미드 [0.07, 0.5], 원딜 [0.015, 0.13], 서폿 [0.04, 0.3].
  `sim/bots.py` LanerBot.trade가 포지션별 값을 읽는다(리스트도 그대로 됨).
- `laner.hp_regen_per_s` 0.0045 → 0.003.
- 체력이 낮아지자 귀환이 늘었다(실제 귀환 모델에 체력 항이 있음). 예전 귀환 배수는 체력이 높던 시뮬에 맞춰 부풀려져 있었다.
  그래서 `sim/laner_calibrated.json`의 `recall_mult`를 탑 1.5 → 0.6, 미드 2.0 → 1.0으로 낮췄다.

## 재검수

- 라이너 기준(`sim.laner_eval --games 150`): OK 87 → 90, 불일치 3 → 3.
  - 바뀐 불일치: 미드 20분 레벨(11 → 12, 이제 OK)이 풀렸다. 대신 미드 20분까지 상점 11회(실제 중앙 9)가 새로 불일치다.
  - 남은 둘(원딜 20분 CS, 14~20분 3명 이상 킬)은 전과 같다.
  - 탑 기지 방문은 5.3(실제 4.7)으로 주의다.
- 4단계 정글 기준(`sim.run_baseline --games 300`): 불일치 0, 주의 2(2분 골드·15분 경험치, 전과 같음).
- 규칙 봇 대비 20분 승률 차(800판): A +0.160, B +0.167, C +0.165로 구별되지 않는다.
- 이른 갱: 정글러가 방문할 때 적 라이너 체력은 0.74~0.77(실제 0.75)로 맞았다.
  다만 갱 성공식에는 체력 항이 없다(target_low_hp 0, 리플레이 라인 방문 700번 근거). 그래서 방문 킬 비율은 거의 그대로다(규칙 봇 26%, 실제 33% ±6).

## 남은 것

- 학습 정글러가 고른 이른 갱이 실제보다 잘 통한다. B는 2:30~3:30에 63%(실제 33% ±14), C는 1:30~2:30에 51%(31% ±12)다.
  성공식 항 가운데 초반에 실제와 다를 만한 것은 시야(seen −1.6)다. 시뮬 라이너가 초반에 와드를 덜 박을 수 있다.
- 미드 상점 횟수, 탑 기지 방문이 조금 많다.
