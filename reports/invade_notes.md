# 카정 검수 (2026-10-24)

질문: 학습 정글러가 카정을 거의 안 한다(1초 동선 행동 비율 0%, 실제 6%). 시뮬레이터가 카정 가치를 잘못 보는가?

## 1. 실제 카정 (리플레이 70판, 정글러 138명, 3~18분) — `python -m sim.invade_check` → `reports/invade_check.md`

| | 판당 카정(적 캠프 3초↑) | 판당 먹음 | 캠프 살아 있었음 | 적 정글러 마주침 | 사망 | 마주쳤을 때 사망 |
|---|---|---|---|---|---|---|
| 실제 | 3.05 | 1.81 | 88% | 34% | 5% | 10% |
| 학습 정글러 stage11_a | 0.15 | 0.01 | 27% | 23% | 7% | - |
| 규칙 봇 | 0.93 | 0.67 | 60% | 25% | 7% | 6% |

- 실제 '먹음'은 5초 이상 머묾 + 살아 있었음(적 정글러가 그 캠프에 마지막으로 머문 뒤 135초 이상)으로 추정. 경기 끝 요약의
  적 정글 몬스터 처치(140명 중앙 14, 20분당 11.5)와 대체로 맞는 크기.
- 실제 카정은 위험하지 않다: 사망 5%, 적 정글러와 마주쳐도 10%.
- 실제 선수는 살아 있는 캠프를 고른다(88%). 당한 쪽 정글러가 135초 안에 그 빈 캠프를 들르는 경우는 8%(250번 중 21번)뿐 →
  '헛걸음' 손해는 작다.

## 2. 시뮬에서 카정이 손해인가

- 강제 실험(학습 정글러, 같은 시드 쌍, 3~15분 무작위 시각에 25초 안 적 캠프를 끝까지 먹으러 감):
  - 살아 있는 캠프 + 적 정글러를 30초 안에 반대편에서 봤을 때: 20분 승률 +0.009 ±0.036(300쌍), 먹음 82%.
  - 강제 뒤 60초 사망률 25%는 강제 안 한 같은 판(29%)과 같음 → 카정이 더 위험하게 만들어져 있지 않다.
  - 같은 조건에서 '우리 캠프 강제'와 비교: 90초 뒤 −0.004 ±0.016, 20분 +0.011 ±0.027(600쌍) → 차이 없음.
- 규칙 봇끼리(600판, 같은 시드): 한 팀 카정 확률 0 / 0.35(기본) / 1.0 / 1.0+살아 있는 캠프만:
  판당 적 캠프 0 / 0.93 / 2.88 / 1.6, 20분 승률 차(기본 대비) +0.012 / 0 / +0.027 / +0.012, 모두 ±0.025~0.030 안.
- 결론: 시뮬에서 카정은 캠프 하나 값(우리 골드·경험치 + 상대 몫 하나 줄임)만큼이고, 그 크기는 결정 하나의 잡음보다 훨씬 작다.
  학습 정글러가 안 하는 것은 '손해라서'가 아니라 '이득이 안 보여서'다. 시뮬이 카정을 벌주는 오류는 찾지 못했다.

## 3. 바꾼 것: 적 캠프 상태 추정(실제 정글러가 아는 만큼)

학습 정글러가 적 캠프에 갔을 때 살아 있던 비율이 27~44%(실제 88%)라 정보부터 맞췄다(`AgentJungler.update_enemy_camps`).
- 처음 생성 시각은 누구나 앎 → 처음엔 '생성 시각에 살아 있음'.
- 보이면 실제 상태(기존).
- 적 정글러가 캠프를 먹을 때 그 정글러를 10초 안에 그 캠프 2,500 안에서 봤으면 어느 캠프인지 앎(동선 추적).
- 새 입력 8개: 캠프 상태를 확인한 뒤 적 정글러가 캠프를 몇 개 더 먹었나(점수판 CS로 앎).
- 관측이 길어져 `Policy.grow`가 첫 층에 0 가중치를 붙인다(예전 모델은 똑같이 동작, 학습 때 모방 표본도 0으로 채움).

재학습 `models/stage11_a`(stage10_a에서 200회, 바닥 0.002): 규칙 봇 대비 20분 승률 차 +0.141(95% +0.117~+0.166),
같은 평가에서 stage10_a +0.112. 카정은 판당 0.04캠프로 그대로.

## 남은 것

- 카정이 실제처럼 나오려면 시뮬에 없는 카정 이득이 있어야 하는데, 데이터로 확인되는 것(사망 위험, 헛걸음)은 이미 비슷하다.
  실제 선수들이 왜 1.8개씩 먹는지는 '남는 시간에 먹을 캠프가 적 쪽에 있어서'일 가능성이 크고, 시뮬 정글러는 그 시간에
  바위게·오브젝트를 더 한다(stage11_a 3~18분 시간 비율: 바위게 19%·오브젝트 14%·라인 17%, 실제 13%·7%·25%,
  `reports/stage11_a_actions.md`).
- 천상계 방식 자체를 따라 하게 하려면 B 갈래(모방 손실)가 맞는 도구.
