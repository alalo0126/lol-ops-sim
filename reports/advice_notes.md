# 조언 검증 정리 (2026-10-26)

질문: 학습 정글러(stage12_a)의 추천이 실제 천상계 경기에서도 더 좋은 선택이었나.

## 1. 결정 하나 단위: 검증 안 됨 (reports/advice_check.md)

리플레이 70판, 정글러 결정 1,148개(3~17분 시작 시각, 1초 동선으로 실제 행동을 붙임).

- 추천과 같은 행동 묶음을 고른 결정 29%. 같은 묶음을 골라도 3분 뒤 실제 예측 승률이 더 좋지 않았음(−0.1%p, 95% −1.6~+1.5). 실제 승패도 차이 없음.
- 결정마다 '추천 − 실제' 시뮬 예측 차이는 시드 8개 평균으로도 신뢰도 0.11(20분)·0.08(3분) → 대부분 시드 잡음.
  시뮬이 "추천이 낫다"고 본 결정 3분의 1과 "실제가 낫다"고 본 3분의 1의 실제 결과는 같았음.
- 실제 행동을 그대로 둔 시뮬의 3분 뒤 변화와 실제 3분 뒤 변화의 상관 0.06. 한 상태에서 3분 뒤를 맞히는 힘이 거의 없음
  (실제도 10명이 만드는 변화라 맞히기 어려운 부분이 큼).

→ "이 분에 이걸 했어야 했다(+12%p)" 같은 분 단위 조언은 근거가 없다. LLM 코치에 이런 숫자를 주면 안 된다.

## 2. 상황 칸 단위: 약하게 맞음 (reports/advice_cells.md, sim/advice_cells.json)

1,000판 실제 정글러-분 27,896개를 시기 × 드래곤 × 팀 골드 × 정글러 상태 칸(97개)으로 묶고, 60개 이상인 67칸에서
상태 40개 × 범주 6개 + 자유 선택 × 3회 시뮬(같은 상태·시드 짝).

- 칸 × 범주 365쌍에서 시뮬 가치와 실제 3분 뒤 차이의 상관 +0.28(95% +0.12~+0.43). 실제 최종 승패 차이와는 +0.08.
- 시뮬 구간이 0을 벗어난 49쌍 중 실제도 같은 방향으로 유의 8쌍(verified), 반대 2쌍(contradicted), 나머지는 실제 쪽 불확실.
- verified 8쌍 중 4쌍이 "드래곤 있을 때 오브젝트"(6~9분, 14~17분). 드래곤을 잡으면 3분 뒤 예측 승률이 바로 오르므로
  반쯤은 정의상 맞는 것. 나머지: 10~13분 골드 비슷할 때 라인 개입 +, 10~13분 골드 뒤질 때 귀환 −, 14~17분 골드 앞설 때 라인 개입 −,
  14~17분 드래곤 있을 때 우리 정글 −.
- 반대 2쌍: 3~5분 골드 쌓였을 때 귀환(시뮬 +3.6 / 실제 −6.2, 실제 61%가 귀환), 10~13분 골드 뒤질 때 카정(시뮬 −3.6 / 실제 +3.3).
- 실제 차이는 선택 편향이 섞여 있음(예: 귀환은 대개 필요해서 함). 인과 효과가 아니라 "같은 칸에서 그걸 고른 천상계 경기가 어땠나".

## 3. 쓸 수 있는 것과 없는 것

- 쓸 수 있음: 칸 단위로 verified인 범주만, "이 상황에서는 보통 X가 낫다(시뮬 +a%p, 천상계 실제 +b%p, n=…)"는 경향 조언.
  LLM 코치는 sim/advice_cells.json의 verified 범주만 근거로 쓰기로 함(코치 스레드 sim/review_cells.py).
- 못 씀: 분 단위 반사실 숫자, verified 아닌 칸의 추천, 귀환·카정 조언(반대 사례 있음).
- 다음에 나아지려면: (1) 시뮬 3분 변화가 실제보다 크게 출렁임(표준편차 18.7 vs 15.5%p, 1분 프레임으로 본 실제는 더 작을 수 있음) →
  교전·킬 변동 줄이기, (2) 칸을 더 잘게(라인 상태·상대 정글 위치) 나누려면 표본이 더 필요, (3) 귀환 가치(아이템) 재검토.
