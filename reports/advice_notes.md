# 조언 검증 정리 (2026-10-26)

질문: 학습 정글러(stage12_a)의 추천이 실제 천상계 경기에서도 더 좋은 선택이었나.

## 1. 결정 하나 단위: 검증 안 됨 (reports/advice_check.md)

리플레이 70판, 정글러 결정 1,148개(3~17분 시작 시각, 1초 동선으로 실제 행동을 붙임).

- 추천과 같은 행동 묶음을 고른 결정 29%. 같은 묶음을 골라도 3분 뒤 실제 예측 승률이 더 좋지 않았음(−0.1%p, 95% −1.6~+1.5). 실제 승패도 차이 없음.
- 결정마다 '추천 − 실제' 시뮬 예측 차이는 시드 8개 평균으로도 신뢰도 0.11(20분)·0.08(3분) → 대부분 시드 잡음.
  시뮬이 "추천이 낫다"고 본 결정 3분의 1과 "실제가 낫다"고 본 3분의 1의 실제 결과는 같았음.
- 실제 행동을 그대로 둔 시뮬의 3분 뒤 변화와 실제 3분 뒤 변화의 상관 0.06. 한 상태에서 3분 뒤를 맞히는 힘이 거의 없음
  (실제도 10명이 만드는 변화라 맞히기 어려운 부분이 큼).

→ "이 분에 이걸 했어야 했다(+12%p)" 같은 분 단위 조언은 근거가 없다. LLM 코치에 이런 숫자를 주면 안 된다.

## 2. 상황 칸 단위: 검증 안 됨 (reports/advice_cells.md, sim/advice_cells.json)

1,000판 실제 정글러-분 27,896개를 시기 × 드래곤 × 팀 골드 × 정글러 상태 칸(97개)으로 묶었어요. 60개 이상인 67칸에서
상태 40개 × (범주 6개 + 자유 선택) × 3회 시뮬을 돌렸어요(같은 상태·시드 짝).

- 실제 범주는 결과를 보지 않고 붙인다(intent_label: 1분 끝 위치·귀환만, 에픽 처치·교전 관여 제외).
  1차는 stage6.label(결과 기준)을 써서 '용을 잡은 분 = 오브젝트'였다. 그래서 처치 효과가 실제 3분 뒤 차이에 기계적으로 들어갔고,
  상관 +0.28(95% +0.12~+0.43), verified 8쌍(4쌍이 오브젝트)으로 나왔다. LLM 코치 스레드가 짚어 줘서 고쳤다.
- 고친 뒤: 칸 × 범주 324쌍에서 시뮬 가치와 실제 3분 뒤 차이의 상관 **−0.11(95% −0.22~+0.01)**, 실제 승패 차이와는 −0.15, 부호 일치 39%.
  시뮬 구간이 0을 벗어난 42쌍 중 verified 2쌍(드래곤 있을 때 오브젝트: 6~9분 n=137, 14~17분 n=12), contradicted 2쌍.
- 시뮬 쪽은 첫 1분 행동을 묶는 방식이라 원래 시도 기준이었다. 실제 쪽 1분 끝 위치 라벨에도 잡음이 있다(1분 프레임).
- 실제 차이에는 선택 편향이 섞여 있다(예: 귀환은 대개 필요해서 함). 인과 효과가 아니다.

## 3. 쓸 수 있는 것과 없는 것

- 지금 학습 정글러의 판단은 결정 단위로도, 상황 칸 단위로도 실제 천상계 결과와 맞지 않는다. 시뮬이 좋다고 보는 범주와
  실제로 좋았던 범주가 거의 무관하다(오히려 약간 반대 방향).
- 쓸 수 있음: verified 2쌍("6~9분 드래곤 있을 때 오브젝트 시도")뿐이고, 이건 시뮬 없이도 아는 조언이다.
  LLM 코치에는 시뮬 추천 대신 실제 데이터 사실(1,000판·리플레이 통계, 칸별 천상계 선택 비율과 실제 결과)을 근거로 주는 편이 낫다.
- 못 씀: 분 단위 반사실 숫자, 칸별 시뮬 추천 전반.
- 다음에 나아지려면: (1) 시뮬 3분 변화가 실제보다 크게 출렁임(표준편차 18.7 vs 15.5%p, 1분 프레임으로 본 실제는 더 작을 수 있음) →
  교전·킬 변동 줄이기, (2) 칸을 더 잘게(라인 상태·상대 정글 위치) 나누려면 표본이 더 필요, (3) 귀환 가치(아이템) 재검토.
