# 5단계 메모: 정글러 강화학습

2026-10-20. 판정표는 [stage5_eval.md](stage5_eval.md)(4,000판).

## 결론

학습 정글러는 같은 경기·같은 팀에서 규칙 봇 정글러 자리만 바꿨을 때 20분 예측 승률을 **0.496 → 0.804 (+0.308, 95% CI +0.299~+0.317)** 로 올렸다. 경기의 85.6%에서 학습 정글러 쪽이 높았다. 블루·레드 어느 쪽에서도 비슷하다(+0.317 / +0.299).

버그 악용 점검에서 기계적 버그 악용 2건(이동 진행 손실, 노출 기록 초기화)은 학습 전에, 연속 갱 1건은 학습 중에 찾아 시뮬레이터를 고쳤다. 고친 뒤 이어서 학습했고 위 수치는 고친 시뮬레이터 기준이다. 남은 우위는 아래 민감도 점검에서 갱·시야·드래곤 가정을 크게 바꿔도 +0.17 이상 유지됐다.

다만 학습 정글러의 운영은 실제 천상계와 다른 지점이 있다(아래 "실제 범위 밖"). 시뮬레이터 버그라기보다 **규칙 봇 상대가 수동적이고 갱 모델이 자리표시라서** 생기는 차이로 보이며, 6단계에서 "시뮬레이터 오류 / 조건 차이"로 분류할 후보다.

- 3단계 문서의 "골드 차이만으로 76.0%(196판)"과 같은 수준이다.
- 20분 모델은 20분 넘게 간 735판만 쓴다. 일찍 끝난 일방적인 경기가 빠져 계수가 다소 작게 나올 수 있다.
- 유충 계수는 마리당 0.03~0.10, 전령은 0.04로 드래곤보다 훨씬 작다. 학습 정글러가 윗쪽 오브젝트를 버린 이유로 보인다.

### 같은 인터페이스로 규칙 봇을 돌린 확인

학습 정글러와 똑같은 행동·결정 시점으로 규칙 봇의 선택만 넣은 교사(`sim/teacher.py`)는 300판에서 규칙 봇 그대로와 승률 차이 −0.007(±0.016), 10분 CS 64.5 vs 64.7이었다. 행동 인터페이스가 규칙 봇의 운영을 손실 없이 표현한다는 뜻이다.

## 버그 악용 점검

### 1. 찾아서 고친 것: 연속 갱

첫 학습 정책(400회)은 갱의 22%를 같은 라인에 40초 안에 다시 들어갔고, 이때 성공률(0.69)이 첫 갱(0.62)보다 높았다. 갱을 버틴 라이너가 체력이 깎이고 점멸이 빠진 채 라인에 그대로 남았기 때문이다. kk 귀환 기준(35% 미만 + 웨이브 밀림)은 웨이브 모듈이 없어 거의 발동하지 않는다. 라이너 갱 후 대응을 넣고 이어서 학습한 뒤에는 연속 갱이 15%로 줄고 성공률(0.625)이 첫 갱(0.614)과 같아졌다.

### 2. 민감도: 가정을 바꿔도 우위가 남는가 (600판씩, 학습 없이 같은 정책)

| 바꾼 값 | 규칙 봇 | 학습 정글러 | 차이 (95% CI) | 20분 킬 학습/규칙 | 드래곤 학습/규칙 |
|---|---|---|---|---|---|
| 기본 | 0.496 | 0.804 | +0.308 (+0.299~+0.317) | 8.8 / 4.6 | 2.52 / 1.30 |
| 갱 성공 확률 낮춤(bias −0.6) | 0.515 | 0.720 | +0.205 (+0.181~+0.230) | 6.6 / 3.8 | 2.46 / 1.30 |
| 갱 성공 확률 크게 낮춤(bias −1.2) | 0.500 | 0.671 | +0.171 (+0.146~+0.196) | 5.4 / 3.2 | 2.41 / 1.30 |
| 라이너가 더 쉽게 후퇴(0.7 → 0.4) | 0.518 | 0.772 | +0.254 (+0.229~+0.279) | 8.8 / 4.8 | 2.50 / 1.33 |
| 들킨 갱 불이익 2배(seen −1.6 → −3.0) | 0.517 | 0.809 | +0.292 (+0.270~+0.314) | 8.4 / 4.0 | 2.51 / 1.35 |
| 적 규칙 봇이 오브젝트를 더 자주 감(0.25 → 0.8) | 0.497 | 0.771 | +0.273 (+0.246~+0.301) | 8.9 / 4.9 | 1.91 / 1.52 |
| 오브젝트 합류 라이너 피해 0 | 0.500 | 0.781 | +0.281 (+0.257~+0.305) | 8.6 / 4.7 | 2.45 / 1.25 |

갱 모델이 자리표시라 가장 의심스러운데, 갱 성공 확률을 규칙 봇 킬이 4.6 → 3.2로 줄 만큼 낮춰도 +0.17이 남는다. 우위가 특정 값 하나에 기대지 않는다.

### 3. 확인했지만 문제 없던 것

- 우물에서 귀환: 부활 뒤 구매 수단으로 허용. 학습 정글러 결정의 3.7%, 반복 남용 없음.
- 라인 미니언 먹기: 학습 정글러가 한 번도 안 씀(패널티 반영 후 이득 없음).
- 와드: 경기당 0개. 와드는 아군 라이너 후퇴 판단에만 쓰여 정글러에게 이득이 작다. 악용은 아니지만 시야 가치가 과소평가된 모델이라는 뜻이다.
- 교전(조우) 승률: 학습 0.58 vs 규칙 0.54로 큰 차이 없음.

## 학습 정글러가 고른 운영 (요약)

봇 쪽 바위게 근처를 기점으로 미드·봇을 반복 갱하고, 드래곤이 뜨면 바로 잡는다. 윗쪽(탑 갱, 유충, 전령)과 카정, 와드는 거의 버린다. 첫 풀캠은 규칙 봇보다 조금 늦다(CS 24 도달 4.2분 vs 3.3분). 20분 팀 골드 차는 평균 +4,300이다.

## 한계와 다음 단계에 넘길 것

- 상대 9명이 모두 규칙 봇이라, 학습 정글러는 "규칙 봇을 이기는 법"을 배웠다. 특히 드래곤을 다투지 않는 상대 정글 봇과 반복 갱에 적응하지 않는 라이너 봇의 약점을 쓴다.
- 갱·교전 계산식은 자리표시(4단계에서 10분 KDA에만 맞춤). 갱 빈도가 2배가 된 상황은 보정 범위 밖이다.
- 6단계(천상계 비교)에서 학습 정글러가 다르게 고른 지점은 위 표를 기준으로 "시뮬레이터 오류 / 조건 차이"부터 의심해야 한다.
