# 정글러 두 갈래 학습: 라이너 학습 전 기준점 (2026-10-22)

둘 다 models/stage6c에서 출발해 PPO 300회(경기 시드 500000~, 같은 시드). 라이너 9명은 아직 규칙 봇.

- 갈래 A `models/stage6d_a`: 시뮬 20분 예측 승률만.
- 갈래 B `models/stage6d_b`: 승률 + 실제 천상계 정글러 행동 모방 손실(`sim/train.py --real models/stage6c/real_train.npz --real-coef 0.3`; 리플레이 56판 분 시작 상태 1,205개).

| | 갈래 A | 갈래 B | 실제 |
|---|---|---|---|
| 규칙 봇 대비 20분 예측 승률(400판) | 0.791 | 0.794 | - |
| 시험 경기(14판, 302개) 첫 행동 일치 / 묶음 | 13% / 27% | 47% / 60% | - |
| 10분 정글 CS(학습 마지막 회차) | 65 | 54 | 70 |
| 20분 킬(400판) | 5.7 | 5.7 | 5.3 |
| 1초 동선 행동: 우리 캠프 / 카정 / 바위게 | 27 / 0 / 18% | 25 / 0 / 20% | 30 / 6 / 13% |
| 라인 / 오브젝트 / 귀환 | 31 / 7 / 8% | 33 / 7 / 7% | 25 / 7 / 10% |

- B는 시뮬 승률을 잃지 않고 분 시작 시각 결정에서 천상계와 같은 행동을 3.6배 더 자주 고른다. 즉 시뮬 안에서는 천상계 방식도 승률 손해가 거의 없다.
- 하지만 경기 전체 행동 비율은 A와 거의 같다. 모방 표본이 분 시작 시각뿐이라, 이동 중(5초마다) 결정은 여전히 승률만 보고 정한다. B의 10분 CS가 낮은 것도 이 섞임 때문으로 보인다.
- 본 비교는 라이너·아이템 학습 뒤에 다시 한다(그때 모방 표본을 이동 중 시각까지 늘릴 것).
