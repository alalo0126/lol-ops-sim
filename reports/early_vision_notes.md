# 초반 시야 검수 (2026-11-16)

이른 갱 검수에서 학습 정글러가 고른 이른 갱이 실제보다 잘 통했다. B는 2:30~3:30에 63%, 실제는 33%다.
갱 성공식에서 큰 항인 발각(seen, 계수 −1.6, 미검증)이 원인인지 보려고, 시뮬 라이너의 초반 와드를 실제와 비교했다.
도구는 `python tools/early_vision_check.py 200 [정책]`이다.

## 1. 시뮬 라이너가 와드를 덜 박지는 않는다

라이너 1명당 0~5분 와드 수다. 실제는 리플레이 72판(26.21)이고, wardType UNDEFINED(챔피언 스킬 설치물)는 뺐다.

| | 실제 | 시뮬(규칙 봇 200판) |
|---|---|---|
| 탑 | 1.51 | 2.06 |
| 미드 | 1.65 | 2.59 |
| 원딜 | 1.63 | 1.80 |
| 서폿 | 1.19 | 1.96 |

- 시뮬이 오히려 더 많다. 다른 점은 시각이다.
  - 실제 미드·원딜은 0:50 전후(분 0)에 하나 박고, 그 뒤 분당 0.1~0.4개를 고르게 박는다.
  - 시뮬은 라인 시작(1:30) 직후에 몰아 박고, 0분에는 하나도 없다.
- 실제 WARD_PLACED에는 위치가 없다. 그래서 와드가 갱 길목을 덮었는지(seen)는 실제 데이터로 확인할 수 없다.

## 2. 시뮬 갱의 발각 값

5분 전 갱이다(규칙 봇 200판 / 학습 B 200판).

| 대상 라인 | 규칙 봇: 발각 < 0.5 / 점멸 없음 / 성공 | B: 발각 < 0.5 / 점멸 없음 / 성공 |
|---|---|---|
| 탑 | 27% / 4% / 50% | 42% / 40% / 63% |
| 미드 | 99% / 14% / 50% | 100% / 0% / 67% |
| 바텀 | 23% / 3% / 42% | 55% / 0% / 41% |

- 미드 갱은 시뮬에서 거의 늘 안 보인다(발각 평균 0.04). 미드로 가는 길에 와드 노드가 없어서다. 미드 성공률은 lane_bias(−0.54)로 맞춰 놓았다.
- B는 탑에서 안 보이는 때와, 직전 갱으로 점멸이 빠진 대상을 골라 간다. 그래서 탑 갱 이벤트 성공이 63%다.

## 3. 실제와 비교할 수 있는 지표로는 차이가 작다

라인 방문(5초 이상, 1:30~10:00) 정글러 관여 킬이다. 같은 라인 5분 안 재방문을 따로 셌다.

| | 실제 | B | 규칙 봇 |
|---|---|---|---|
| 첫 방문 | 29% ±6 | 34% ±3 | 28% ±3 |
| 5분 안 재방문 | 31% ±6 | 35% ±4 | 31% ±3 |

- 실제도 재방문이 덜 통하지 않는다. 시뮬도 비슷하다. 갱 이벤트 성공률(63%)은 실제의 방문 단위 지표와 직접 비교할 수 없다.
- 실험: 와드 설치를 초당 확률로 흩뿌려도(0.04, 탑 분당 0.28로 실제와 비슷) B의 탑 갱 성공은 57% → 62%로 줄지 않았다. 와드 시각 때문이 아니다.

## 결론

- 시뮬을 바꾸지 않았다. 와드 수는 실제보다 적지 않다. 발각 계수와 와드 위치는 실제 데이터(위치 없음)로 검증할 수 없다.
- 학습 정글러의 이른 갱 강세는 '점멸 빠진 대상 재갱'과 '안 보이는 때 고르기'에서 나온다. 점멸 사용 기록은 Riot 데이터에 없다(kk 아이디어 '스펠 체크'와 같은 한계).
- 확인할 방법이 생기면 볼 것: 리플레이 API로 와드 위치를 얻을 수 있는지, 리플레이 화면 기반 소환사 주문 쿨 확인.
