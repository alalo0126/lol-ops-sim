# 오브젝트·바위게 시간 검수 (2026-10-25)

질문: 학습 정글러가 3~18분에 오브젝트 14%·바위게 19%를 쓴다(실제 7%·13%). 시뮬 오류인가?

## 1. 실측 (리플레이 70판, `tools/objective_fit.py` → `sim/objective_fit.json`)

연습 모드 혼자 실측 대신 실제 경기에서 다수 vs 다수 그대로 쟀다(용 176·유충 묶음 95·전령 69건, 20분까지).

| | 용 | 유충(묶음) | 전령 |
|---|---|---|---|
| 처치 인원 평균(1 + 어시스트) | 1.97 (혼자 41%) | 1.44 (혼자 65%) | 2.03 (혼자 41%) |

| 생성 뒤 처치까지(중앙) | 64초 (첫 용 201초, 이후 33초) | 41초 | 64초 |
| 처치 뒤 90초 안 귀환(구매) | 65% | 68~71% | 74~75% |
| 받은 피해(최대 체력 대비, 혼자 친 몫) | 0.31 ±0.04 | 0.21 ±0.06 | 0.34 ±0.06 |
| ±30초 둥지 근처 사망(처치 팀/상대) | 0.27 / 0.47 | 0.31 / 0.34 | 0.30 / 0.38 |

- 받은 피해는 정글러-분(3~19분, 2,240) `damageStats.totalDamageTaken` 증가를 처치 몫(1/인원)·캠프 수·킬 관여·사망으로 회귀한 계수.
  챔피언·아이템별 차이는 판 수가 부족해 평균으로 넣었다(시뮬 정글러는 챔피언 구분이 없음).
- 처치 시간은 시뮬 공식(HP / (정글러 dps × epic_dps_factor + (인원−1) × helper_dps))과 같은 표본으로 맞추면
  epic_dps_factor 0.75(이전 0.8), helper_dps 97~116(이전 70). 공식 자체는 실제와 대체로 맞았다.

## 4. 남은 차이의 원인

1. **학습 정글러가 오브젝트를 더 많이 가져간다.** 용 둥지 방문 3.2회(실제 2.0), 그중 우리 팀 처치 60%(실제 37%), 판당 용 2.07(규칙 봇만일 때 1.46,
   실제 팀당 1.24). 상대 규칙 봇의 다툼은 오히려 실제보다 세다(상대 처치 9%·사망 14% vs 실제 3%·6%). 용 가치가 승률 모델에서
   크기 때문(12분 용 1개 ≈ 780G). 이 값이 상관일 뿐인지 1,000판으로 확인: 킬·포탑을 더 넣어도 용 계수가 같다(12분 0.228 → 0.221) → 과대평가 증거 없음.
2. **첫 용 시각.** 실제는 생성 뒤 중앙 201초(8.3분)에 잡는데 시뮬은 53초. 이후 용은 실제 33초로 시뮬(46초)과 비슷하다. 첫 용만 늦는 이유
   (그 시각 2번째 정글 돌기·첫 귀환·라인 주도권)는 타임라인·정글러 동선만으로는 드러나지 않았다. 첫 용 처치 정글러 레벨 중앙 6, 혼자 37%.
3. 둥지에 머무는 시간이 긴 것(용 방문 17초 vs 실제 7초)은 실제 선수가 들렀다가 그냥 떠나는 방문(살아 있는데 아무도 안 잡은 방문 ~33%)이
   많기 때문. 시뮬 정글러는 오브젝트를 시작하면 끝까지 친다.
