# 롤 패치 연표: 정글·오브젝트·시스템 (9.1 ~ 26.22)

공식 한국어 패치 노트(leagueoflegends.com/ko-kr) 177개를 읽고 소환사의 협곡 **정글·에픽 몬스터·포탑·미니언·보상·이동(민병대·순간이동)·시야** 변경만 모은 연표다. 챔피언·아이템 개별 수치, 아레나·칼바람·아수라장·클래식 모드, 스킨은 뺐다.

- 원문: `knowledge/patch_notes/<버전>.md` (본문 텍스트), 목록 `knowledge/patch_notes/index.csv` (게시일·제목·주소)
- 자동 발췌: `knowledge/patch_system_extract.md` (`python -m tools.patch_notes_extract`로 다시 만듦). 이 연표는 그 발췌를 사람이 읽고 줄인 것.
- 새 패치 받기: kk PC에서 `python -m tools.patch_notes_fetch` (클라우드는 사이트 접속 차단). 받은 파일을 `knowledge/patch_notes/`에 넣고 발췌 도구를 다시 돌리면 된다.
- 버전 표기: 2025~ 공식 이름은 25.S1.1 / 25.04 / 26.1 형식, Riot API gameVersion은 15.x / 16.x (26.20 = 16.20).
- 표기: "A→B"는 패치 노트의 이전값⇒새값. 원문이 모호한 줄은 그렇게 적었다.

## 빠진 구간과 위키 보충

- **9.4~9.17, 9.1 이전(2009~2018) 공식 노트는 사이트에 없다**(한국어·영어 모두). 이 구간은 `patch_timeline_wiki.md`에 위키 요약으로 채웠다(**미검수**, 공식과 겹치는 항목 12개로 점검해 모두 일치). 옛 영상 판별에 쓸 핵심: 캠프 첫 생성 1:55(~5.21) → 1:40(5.22) → 1:30(7.22) → 0:55(26.01), 바위게 첫 생성 2:15(7.22) → 2:00(8.10) → 3:15(9.9), 전령 신설 5.22, 원소 드래곤 6.9, 첫 용 2:30 → 5:00(8.23), 포탑 방패 신설 8.23.
- 13.2는 공식 이름이 13.1b. 10.17은 원문 파일명이 10.16b로 받혀 있던 것을 10.17로 고침.
