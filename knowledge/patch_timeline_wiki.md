# 패치 연표 보충: 9.17 이전 (위키 요약, 미검수)

공식 사이트에 없는 **9.4~9.17**과 **9.1 이전(2009~2018)** 구간을 커뮤니티 위키(wiki.leagueoflegends.com, leagueoflegends.fandom.com)로 채운 것이다. 본편은 `patch_timeline.md`(공식 노트 기반).

## 읽기 전에

- **미검수.** 클라우드와 kk PC 작업 VM 모두 위키 직접 접속이 막혀 있어, 웹 읽기 도구가 돌려준 **요약**을 옮겼다. 원문 문장 그대로가 아니다.
- 정확도 점검: 공식 노트와 겹치는 9.23 이후 항목 12개(전령 9.23 8분·6분 재생성·눈 4→1초, 남작 버프 210→180초, 용 9.23 체력 2,650·처치 골드 100→25 핫픽스, 방패 골드 160→120(9.23 핫픽스)·120→160(10.5)·160→175(12.22), 첫 포탑 150→300(14.11), 칼날부리 외 캠프 리젠 150→120초(9.23), 민병대 10.8·11.6·13.10)는 **모두 공식과 일치**했다.
- 다만 일부 문서(강타, 사냥꾼의 마체테)는 요약이 버전 번호를 뒤섞어 **버전이 확실한 항목만** 넣었다. 버전 번호가 문서마다 다르게 나온 건 뺐다.
- 시즌 표기: 시즌 N 프리시즌 = V(N−1).20~23 근처 패치(예: 2017 시즌 → V6.22, 2018 → V7.22, 2019 → V8.23).

## 9.4~9.17 (2019.02~2019.08)

버전 문서 V9.4~9.8, 9.11, 9.12, 9.14(일부), 9.17을 읽었고 V9.10·9.13·9.15·9.16은 읽기 실패. 대신 주제 문서(용·남작·전령·바위게·캠프·포탑·민병대) 패치 기록에서 이 구간 항목은 아래뿐이었다.

- 9.4: 첫 웨이브 탑·바텀 미니언 유령화 18→28초(미드 18초 그대로).
- 9.6: 미니언·몬스터 현상금(CS 골드 앞섬) 150골드당 50 → 200골드당 50, 평균 계산 나눗수 4→4.3, 서폿 아이템 골드도 계산에 포함.
- **9.9: 바위게 첫 생성 2:00 → 3:15.** (이후 12.22에 3:30, 26.01에 2:55 — 본편)
- 9.5·9.7·9.8·9.11·9.12·9.14·9.17: 협곡 정글·오브젝트·시스템 변경 없음(칼바람 등 다른 모드만).

### 정글 일반
- 시즌 3(2013): 사냥꾼의 마체테 도입(정글 아이템 시대).
- 시즌 4: 상위 정글 아이템 효과가 몬스터 처치에만, 두꺼비(Wight) 캠프 추가.
- 시즌 5(V4.20): 정글 개편·협곡 그래픽 업데이트. 강타 업그레이드 아이템 4종(밀렵꾼의 칼·정찰자의 칼·척후병의 군도·추적자의 검)과 마법부여, 캠프별 강타 보상(두꺼비 독·돌거북 기절·칼날부리 와드 탐지·늑대 정령·블루 마나·레드 체력). **바위게 첫 등장(V4.20).**
- 5.1: 소프트 리쉬 5번 후 하드 리셋, 5.10 리쉬 거리 750→700. 5.19 몬스터 '인내심' 시스템.
- 5.22: 추적자의 칼이 밀렵꾼·정찰자 대체, 사냥꾼의 부적(마나) 신설, 마체테 350G.
- 6.22: 칼날부리 3→5마리(큰 칼부 체력 약 −50%), 돌거북 쪼개지는 형태, 몬스터 레벨 구간 성장. 식물(폭발 열매·정찰 꽃·꿀열매) 신설. 제어 와드 신설(75G).
- **7.22: 모든 캠프 CS 4로 통일**(칼날부리 1마리 0.4 등), 늑대 1레벨에 1레벨업.
- 8.4: 추적자의 칼 삭제.
- 8.10: 캠프보다 레벨 높을 때 경험치 감소(레벨당 5%) 삭제, 정글 경험치를 몬스터 레벨 기반으로.
- 8.23: 정글 아이템의 '몬스터 사냥꾼'(라인 미니언 골드 −10) 불이익 삭제, 캠프 경험치 하향.
- 9.2: 정글 경험치 하향(블루 115~180 → 115~143.75 등, 본편 9.2와 일치).

### 강타
- 6.24 핫픽스 전후로 충전 2회(75초→90초 충전, 1:25→1:40 첫 충전 시작), 대형 몬스터 처치 시 체력 회복 등. 위키 요약이 이 문서의 버전을 뒤섞어 **세부 버전은 신뢰 못 함.** 강타 피해 390~1,000(레벨)은 11.10 전까지 유지(본편).

### 바위게
- V4.20 신설. 7.22 첫 생성 2:25→2:15. 8.10 체력·골드·경험치 상향, **첫 생성 2:15→2:00, 리젠 180→135초, 첫 생성 때 위·아래 둘 다(둘 다 죽어야 리젠 시작)**. 8.11 리젠 135→150초, 이속 성소 75→90초. 9.2 골드·경험치 하향. 9.9 첫 생성 2:00→3:15.

### 협곡의 전령
- **V5.22 신설: 4:00 생성, 남작 둥지, 처치 시 '파멸의 전조' 버프(귀환 강화 등).** 6.1 기본 레벨 6. 6.9 4분 → 6분, 재생성 삭제, 버프 대신 '공허의 일격'. 6.22 6분 → 10분. **7.9 '전령의 눈' 도입(줍고 소환해 포탑 돌진)**, 처치 골드 50→25. 7.13 골드 25→100. 7.22 10:00 → 9:50. 8.9 소환 전령 포탑 돌진 피해 강화. 9.23 8분·6분 재생성(본편).

### 드래곤
- 6.9: **원소 드래곤 4종**(화염·대지·바람·바다) 분화와 누적 버프, 장로 드래곤(120초, 원소 버프 +50%).

- **8.23: 첫 용 2:30 → 5:00**, 리젠 6→5분, 처치 골드 25→100, 경험치 150~330, 장로 리젠 8→6분. 원소 버프 수치 조정.

- 5.23(2016 시즌): 장화 마법부여였던 민병대가 **기본 효과**로. 20분부터 우물 방문 시 이속 +175%(8초 감소), 체력·마나 회복. 6.9 7초, 이속 75~150%(게임 시간 비례). 이후 10.8 부활 민병대 등은 본편.
